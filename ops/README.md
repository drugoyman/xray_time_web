# Исходники с сервера

Импортированы 27.10.2026 по SFTP из явно выбранных путей. Файлы сохраняются
без изменения содержимого; SHA-256 и исходные пути перечислены в source-manifest.json.
Это запись фактической реализации, а не новый релиз служебных средств.

- `scripts/` — backup, health, offsite.
- `scripts/vpn-crm-relay.py` — фиксированный NAT на сервере CRM, отдельный от VPN-хоста.
- `systemd/` — service/timer для этих трёх задач. Offsite timer на сервере отключён.
- `systemd/vpn-crm-relay.service` — применяет/снимает только CRM relay chains.
- `fail2ban/` — конфигурация host jail sshd.
- `compose/` — candidate 2.8.8 с закреплённым digest и ограничением логов.
- `network/` — Netplan overlay второго IP, применённый 27.10; основной DHCP сохранён.
- `historical/2026-10-26/` — deploy, rollback, baseline и промежуточный compose.

Скрипты содержат пути к закрытым конфигурациям, а не сами ключи или пароли.
Копировать эти файлы в /etc или запускать их автоматически при clone нельзя.
Они требуют серверных зависимостей, правильных путей, закрытых сертификатов
и сохранённой БД. Для backup-скрипта нужны права чтения секретов.

Исторические deploy/rollback имеют побочные эффекты: остановка контейнера,
пересоздание и восстановление базы. Их не запускали при импорте в Git.
Некоторые значения привязаны к состоянию 26.10.2026 и требуют повторной проверки.

Проверка перед первой публикацией: просмотр исходников, синтаксическая компиляция
в памяти, проверка diff и поиск секретов. Полноценный тест восстановления и
тест выгрузки в Drive в рамках публикации не проводились.
