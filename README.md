Репозиторий публичный. Пароли, UUID доступа, приватные ключи, базы, QR-коды
с доступом, реальные конфигурации клиентов, OAuth-токены и архивы здесь не хранятся.
Скрипты содержат только пути к закрытым данным на сервере. Дамп сервера не заменяет
документацию и не должен попадать в Git.

Публикация файлов в этом репозитории **не развёртывает** их на сервере.
